# 后台管理（网页版）

一个跑在你自己电脑上的网页后台，用来改作品集和文案。改完点「保存并生成」，
网站和小程序的数据（和图片）一起更新。

## 怎么启动

**双击项目根目录的 `启动后台.command`**

它会起一个本地服务并自动打开浏览器：

```
http://127.0.0.1:4400
```

关掉终端窗口就停了。想再开就再双击一次。

> 不用装任何东西，只用 macOS 自带的 Node 和 sips。

## 中英文

顶栏右上角有 **中文 / English** 切换，切过去编辑的就是对应语言的文案。
姓名、头衔、地区、各区块文案、相册的文章描述都分语言；品牌名、微信号、头图、二维码两端共用。

（网站和小程序前台也各有一个切换键，读者自己切。）

## 能改什么

| 栏目 | 内容 |
|---|---|
| 基本信息 | 品牌名、姓名、头衔、地区、微信号、首屏大图、二维码 |
| 首页文案 | 眉标、两行大标题、副标题、两行说明 |
| 作品集 | 区块文案 + 相册（增删、排序、改名、描述、品牌、标签、图片增删排序） |
| 服务与报价 | 两个分类、三个计价维度、报价说明、服务包含 |
| 关于 | 两段介绍 + 合作品牌 |
| 联系 | 三步流程、二维码、微信号、地区 |
| 生成 / 发布 | 只生成不保存；查看生成报告（张数、小程序包体积） |

## 图片怎么处理

- 后台里上传的图会先压成 **长边 1600 / 质量 86** 存到 `assets/uploads/`，网站直接用这张；
- 点「保存并生成」时，再给小程序出一份 **长边 660 / 质量 72** 的副本（`miniprogram/assets/…`），
  因为小程序主包只有 2MB。
- 每本相册的**第一张图就是封面**，用图下方的 `‹` `›` 调整顺序。

## 保存之后

- **网站**：刷新浏览器就生效（`http://127.0.0.1:8123` 或后台自带的 `http://127.0.0.1:4400/index.html`）。
- **小程序**：微信开发者工具里按 **⌘B** 重新编译，模拟器就能看到；真机预览扫码。
- 生成报告里如果显示 `ok:false`，说明有图片丢了或者小程序包超 2MB，需要删图或压缩。

## 文件在哪

```
content/content.json      ← 所有内容都在这里（后台就是编辑它）
tools/build.js            ← 生成脚本：content.json → 网站数据 + 小程序数据 + 压缩图
admin/                    ← 这个后台
assets/uploads/           ← 后台上传的原始图
js/content-data.js        ← 自动生成（网站读）
miniprogram/data/content.js ← 自动生成（小程序读）
```

不要手改上面两个「自动生成」的文件，下次生成会被覆盖。

## 说明

- 后台只监听 `127.0.0.1`，只有本机能访问，没有密码。
- 以后如果小程序注册了 AppID、想做成「在线后台」，可以接微信云开发（数据库 + 云函数），
  现在的 `content.json` 结构可以直接搬过去。
